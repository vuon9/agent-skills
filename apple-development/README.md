# Apple Development

Use this skill when an agent needs a safety checklist for Apple platform work
before changing projects, signing settings, simulators, archives, or release
readiness.

## Good Use Cases

- Check whether Xcode, selected developer directory, simulators, and signing
  identities are ready for local development.
- Inspect bundle identifiers, build numbers, teams, entitlements, and shared
  schemes before release work.
- Diagnose common archive, simulator, signing identity, SDK, or App Store
  Connect readiness failures.
- Decide what evidence is needed before claiming an Apple build, test, or
  archive succeeded.

## Not For

- Public App Store submission policy.
- Full TestFlight automation; use `ios-testflight-release`.
- Developer ID macOS DMG distribution; use `macos-release`.
